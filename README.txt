CAMPUS MANAGEMENT SYSTEM

Developed in PHP for Internet Programming 621 Assignment.

FILES INCLUDED:
- index.php
- parking.php
- library.php
- performance.php
- functions.php

HOW TO RUN:
1. Install XAMPP
2. Copy folder into htdocs
3. Start Apache
4. Open browser
5. Go to:
   http://localhost/CampusManagementSystem

FEATURES:
- Parking Permit Management
- Library Borrowing & Fine Management
- Student Performance Analytics
